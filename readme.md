# Harsh Kumar — Personal Portfolio

This repository contains the source code for my personal student portfolio website. It serves as a digital showcase of my journey as a third-year Computer Science and Engineering (B.Tech CSE) student and aspiring frontend developer based in Lucknow, Uttar Pradesh, India. 

The site is built from scratch focusing on semantic structure, clean visual hierarchy, and accessible design.

## Features

* **Semantic HTML5:** Built with accessibility in mind, including skip-links and ARIA labels.
* **Custom CSS3:** Fully responsive design utilizing CSS Grid and Flexbox without relying on external CSS frameworks.
* **Custom Typography:** Integration of Google Fonts (DM Mono, DM Sans, and Playfair Display) for a clean, editorial look.
* **CSS Art & Animations:** Includes custom CSS-based visual elements (e.g., the browser card, interactive plant, and recipe mockups).

## Running the Project Locally

Since this is a static website, no complex build tools or dependencies are required.

1. Clone the repository:
   ```bash
   git clone https://github.com/FrostAbsolute/FrostAbsolute.git
   ```
2. Navigate to the project directory:
   ```bash
   cd FrostAbsolute
   ```
3. Open `index.html` in your preferred web browser, or use a local development server (like VS Code's Live Server extension) to view the site.
